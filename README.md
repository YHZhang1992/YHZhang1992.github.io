# Yu-Hang Zhang — portfolio

A static, responsive personal website for GitHub Pages. It has no build step or runtime dependencies.

## Preview locally

```sh
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Publish to GitHub Pages

Create the public repository `YHZhang1992.github.io` under the `YHZhang1992` account. Push these files to its `main` branch. In **Settings → Pages**, set **Build and deployment → Source** to **Deploy from a branch**, then select `main` and `/ (root)`. The site URL will be `https://YHZhang1992.github.io/` once GitHub finishes publishing.

All featured projects link only to public repositories. Publications link to their DOI pages; the publications, social profiles, and contact email are deliberately public-facing.
